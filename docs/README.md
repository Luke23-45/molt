# Molt — Documentation

Two directories, two jobs:

- **[`notes/`](./notes/README.md)** — the design: thesis, boundaries, guarantees, and positioning ([01–08](./notes/README.md)). Decided. Changed only with the implementation, never ahead of it silently.
- **[`implement_plan/`](./implement_plan/README.md)** — the executable engineering plan: architecture, repository layout, tooling gates, per-module specs, test inventory, adapter specs, CI and release ([00–06](./implement_plan/README.md)), with every deliverable tracked in the [ledger](./implement_plan/ledger.md). The plan implements the notes; any refinement is recorded as an ADR and mirrored into the notes in the same change.

Start with [`notes/01-thesis-and-boundaries.md`](./notes/01-thesis-and-boundaries.md), then [`implement_plan/00-system-architecture.md`](./implement_plan/00-system-architecture.md).
